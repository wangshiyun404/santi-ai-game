# 《三体：三体游戏》低多边形 3D 剧情探索游戏 — 产品需求文档（PRD）v0.1

> 制作方式：逆向 Sac《小王子》管线（PRD → 视觉锚点 → Tripo 资产 → Agent 在 Blender 搭建 → Unity 打包）。
> 定位：非官方同人改编，教学/研究用途，原著 © 刘慈欣。
> 目标时长：15–20 分钟可玩内容，WebGL + macOS 双端。

---

## 1. 一句话概念

玩家戴上"V装具"进入《三体》游戏，以第三人称在三个纪元场景中漫步、拾取线索、触发原著原句旁白，亲历"乱纪元脱水"、"人列计算机"与"三日凌空"，最后在红岸基地听到那句"不要回答"。

## 2. 设计支柱（对应 Sac 的三条）

| Sac《小王子》 | 本作《三体》 |
|---|---|
| 温柔、留白、驯养 | 冷峻、宏大、沉默 |
| 低多边形手作感 ≈ 原著水彩 | 低多边形 ≈ 原著里 V 装具游戏的粗糙 CG 质感（风格合法性来自原著） |
| 角色在大场景里很小 → 孤独 | 人物不超过画面高度 1/10 → 文明在宇宙尺度前的渺小 |
| 每个星球"读"一章原著 | 每个纪元"读"一章原著，旁白全部用原句 |

## 3. 玩法

- **视角**：第三人称越肩跟随相机，鼠标/右摇杆环顾，WASD/左摇杆移动，无跳跃、无战斗。
- **核心动词**：走、看、靠近、触发。靠近"线索物"（发光的低多边形物件）按 E 触发旁白与字幕。
- **推进**：每个场景有 3–5 个线索物，全部触发后出现"纪元之门"（原著里的游戏登出/升级提示），进入下一场景。
- **UI**：极简。左上角纪元名与倒计时（乱纪元时的"倒计时"致敬汪淼眼中的倒计时），底部字幕，无小地图。

## 4. 场景与关卡

### 场景 0：红岸基地（序章 + 尾声共用）

- **地点**：雷达峰山顶，巨型抛物面天线、低矮军绿营房、铁丝网、落叶松。黄昏，深蓝天色。
- **序章玩法**：玩家（叶文洁视角）走向主控室，触发 3 条线索 → 按下发射键 → 画面全白 → 进入三体游戏。
- **尾声玩法**：回到同一场景，夜晚，收到"不要回答！不要回答！！不要回答！！！"字幕，玩家可选择按键或离开，两种结局字幕。
- **资产**：A 类（Tripo）：抛物面天线+塔、主控台、军用吉普。B 类（几何体）：营房、围栏、山体、松树。

### 场景 1：乱纪元·脱水

- **地点**：龟裂荒原，远处一座金字塔，单一白昼巨日。
- **线索物**：①脱水人卷（"脱水——"）；②周文王的占卜竹简；③金字塔门口的追随者；④烈日下的干湖床。
- **动态事件**：玩家走到荒原中央后，太阳迅速坠落、气温骤降，天色由白转深蓝，大地结霜（材质 lerp），字幕"乱纪元开始了"。
- **资产**：A 类：金字塔、脱水人卷、竹简。B 类：地形、裂缝贴花、干枯树桩。

### 场景 2：人列计算机

- **地点**：秦始皇的平原，三千万士兵组成的"秦一号"方阵，一座高台。
- **玩法**：玩家先在地面方阵的"总线通道"里穿行（士兵举黑白旗，波浪式翻转），再登上高台俯瞰全局。
- **线索物**：①一名举旗士兵（"你是一个门电路"）；②总线骑兵（"系统总线"）；③高台上冯·诺依曼的沙盘（"这是一台计算机！"）；④秦始皇的剑。
- **动态事件**：登台后，整个方阵像电路板一样闪动，运算三体轨道；随后三日凌空 → 过渡到场景 3。
- **资产**：A 类：士兵基准模型（低面数，GPU 实例化 3 万个）、高台、沙盘。B 类：平原、旗帜（quad）、总线道路。

### 场景 3：三日凌空（短场景，1–2 分钟）

- **地点**：同一平原，三颗太阳同时升起。
- **玩法**：几乎不可操作，玩家只能缓慢行走，世界在 60 秒内被蒸发：方阵溃散、建筑融化（顶点位移）、天空转为白色。
- **字幕**：原著"三日凌空"段落摘句。结束后切回红岸尾声。

## 5. 角色

| 角色 | 出现场景 | 是否绑骨 | 动作 |
|---|---|---|---|
| 玩家角色（无名"V装具"玩家 / 斗篷人） | 全部 | 是 | idle、walk、look、interact（伸手触碰） |
| 叶文洁 | 场景 0 | 是 | idle、walk、press_button（IK 微调手接触按键） |
| 追随者 / 周文王 | 场景 1 | 是 | idle、kneel |
| 士兵（基准） | 场景 2 | 否（两个静态 Pose：黑旗/白旗） | 几何节点/实例化切换 |
| 冯·诺依曼、牛顿、秦始皇 | 场景 2 高台 | 是 | idle、point |

> 所有角色面部只做几何平面，不做五官细节；对白全部用旁白字幕，不做口型。

## 6. 美术规范

- **面数**：道具 2k–10k 面；主角 ≤ 8k；士兵基准 ≤ 600。
- **材质**：纯色 flat shading，每场景色板不超过 6 色。
- **色板**：
  - 红岸：军绿 #4B5A3A、铁锈红 #8B3A2F、深蓝 #1B2A4A、暖窗 #F2B866
  - 乱纪元：灰土 #8C8275、裂缝暗 #4A433C、巨日白 #FFFFFF、霜蓝 #B8C9D9
  - 人列计算机：晨蓝 #5F7A99、石台灰 #6E6E6E、旗黑 #111111、旗白 #F5F5F5
- **光照**：单一方向光 + 环境色，长投影。乱纪元用高强度顶光；红岸用低角度暖光。
- **构图**：相机默认距离角色 6 m、高 2.5 m、俯角 15°，让角色显小。

## 7. 技术

- **引擎**：Unity 6 LTS，URP，WebGL + Standalone macOS。
- **资产格式**：GLB（Tripo 导出 / Blender 导出），统一 1 unit = 1 m，Y 向上。
- **场景搭建**：Agent 在 Blender 中按参考图摆放 → 导出 `layout.json`（物件名、位置、旋转、缩放）→ Unity 编辑器脚本 `SceneBuilder` 读取 JSON 自动实例化。
- **规模**：士兵用 `Graphics.DrawMeshInstanced` 或 GPU Instancing 材质，3 万实例目标 60 fps（桌面）/ 30 fps（WebGL，实例数降至 1 万）。
- **动画**：Mixamo FBX → Humanoid Avatar → Animator Controller；IK 微调在 Blender 完成后烘焙导出。
- **旁白**：TTS（即梦/豆包）或自录，WAV，字幕 CSV 驱动。

## 8. 制作流程与质检（照搬 Sac 两个工程动作）

1. **视觉锚点先行**：每个场景先定一张主效果图，再补俯视图/斜侧图/局部图；所有 3D 与代码工作以它为唯一标准。
2. **执行与质检分离**：搭场景的 Agent 与盲审 Agent 分开；盲审从正面/侧面/玩家视角截图对照参考图打分，列差异打回。每场景至少 3 轮。
3. **动作微调**：Mixamo 打底 + Auto-Rig Pro IK 改手部接触（按键、持剑）。
